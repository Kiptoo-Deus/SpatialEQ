## SpatialEQ 1.2.0

### macOS: one installer for everything
**`SpatialEQ-1.2.0-macOS.pkg`** is the main download. It installs:
- **SpatialEQ app**: EQ and spatial audio for every app on your Mac (macOS 14.2 or later), in /Applications.
- **VST3 plug-in**: for Cubase, Ableton Live, REAPER, Studio One, Bitwig and other VST3 hosts.
- **Audio Unit plug-in** (new): for Logic Pro, GarageBand and MainStage.

All three are selected by default; untick any of them under **Customize**. Prefer to drag the app yourself? **`SpatialEQ-1.2.0.dmg`** holds the app alone.

This build isn't notarized yet: the first time, macOS blocks the installer. Open **System Settings → Privacy & Security** and click **Open Anyway**.

### Windows: one installer for everything
**`SpatialEQ-1.2.0-windows-x64-setup.exe`** installs the SpatialEQ app and the VST3 plug-in (into `C:\Program Files\Common Files\VST3`). Both are selected by default; untick either one in the setup.

### New
- **Windows app: the same interface as the Mac app**: the 3D scene, the sidebar, the parametric EQ editor, the preset menu (with your own presets) and the output picker. Choosing what to capture (All apps or a device), Close to tray and Start with Windows are all still there.
- **VST3 and Audio Unit plug-ins** with the same interface as the Mac app: the 3D scene, the sidebar and the parametric EQ editor. They also have the same 12 presets and AutoEq import/export. Every control can be automated, including head rotation.
- **Windows setup** for the app and the VST3 plug-in together, with the emblem as the plug-in's folder icon.
- New app and plug-in icons and installer artwork.

### Fixes
- macOS app: the 3D scene now draws at 30 fps when nothing is moving, the rate its spectrum updates, and at 60 fps while you drag or zoom. It previously drew 60 frames a second all the time. The spectrum terrain is also rebuilt only when new audio arrives.
- Plug-in editor: much lower CPU use. The 3D scene redraws only when something changes, and only changed settings are sent to the interface.
- Plug-in editor: if the web view's process stops, the editor reloads itself instead of staying blank.
- VST3 on Windows: the plug-in window now controls the plug-in. In the first Windows build it showed the interface but didn't respond, because the controls were connected before WebView2 had started.
- Windows app: draws at 30 fps when you aren't using the window, the rate its spectrum and meters update. It previously drew at the monitor's refresh rate (60-144 fps) all the time. It still draws every frame while you move the mouse, drag or type.
- Windows app: the file version now matches the release (it still said 1.1.0 in 1.1.1).
